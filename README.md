# Databricks Notebooks

A small collection of Databricks notebooks focused on data engineering, lakehouse workflows, and machine learning in Spark.

## Notebook overview

- Delta table s.ipynb — Overview of Delta table concepts and common lakehouse data operations.
- Loading files in volume SB.ipynb — Examples for loading and working with files stored in a Databricks volume.
- ML Flow.ipynb — High-level examples for experiment tracking and model workflow management with MLflow.
- ML on pyspark.ipynb — Machine learning workflows using PySpark for data preparation, modeling, and evaluation.
- Medallion-runbook.ipynb — Practical reference for medallion architecture patterns across bronze, silver, and gold layers.
- Spark Ops.ipynb — Notes and examples around Spark operations, troubleshooting, and performance awareness.

These notebooks are intended as practical references for learning and experimentation in a Databricks environment.
